Probes are defined once in `docs/parity/probes.json` and run by
`scripts/parity-sweep.ps1`, which writes `target/parity/report.json`. A row
without a probe is **unprobed**: it counts as coverage debt and is the next
audit's first target. `manual` rows are legitimate debt with the checklist in
`docs/install.md`; they are never reported as matched from a test alone.

Ledger files: `docs/parity/ledger/<surface>.md`.

An auditor records per row: `matched` (with evidence), `differs #n`, `missing
#n`, or `not checked — <why>`. "Not checked" is a finding of its own if the
matrix says the capability ships.
